# Project context

## Purpose

Web con turnero + landing, y también un sistema interno para facturación, gestión de turnos y demás para un negocio de reparación autoservicio y mecánica de vehículos.

## Selected profile and architecture

- **Profile:** Laravel + PostgreSQL + Blade
- **Architecture:** Server-centric Laravel application with Blade and PostgreSQL for shared relational data.

## Capabilities

- users and authorization
- durable shared persistence
- file storage

## Explicitly not required now

- Python ecosystem or admin-oriented server tooling

## Current phase

Phase 1 — the public landing at `/` includes a white, sticky CarServ-inspired navigation, red-led FyB identity, image-led sections, and verified WhatsApp contacts for both branches.

## Next objective

Replace provisional photography, add verified social links when supplied, then define the real appointment-booking slice.
