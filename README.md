# FyB

Web con turnero + landing, y también un sistema interno para facturación, gestión de turnos y demás para un negocio de reparación autoservicio y mecánica de vehículos.

## Getting started

Generation does not install dependencies or create external resources.

```sh
./bin/kit help
./bin/kit doctor
./bin/kit status
./bin/kit install
```

See [COMMANDS.md](COMMANDS.md) for the truthful capability contract and [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) for current architecture.
